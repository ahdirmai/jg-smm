# P1-04 — Desired-state reconciler

> Phase: **P1 — Account Lifecycle & Provisioning** · Priority: **P0** · Estimate: **L** · Depends on: P1-03

## Context

Fase inti operasional: operator menambah akun dari UI → BE provisioning container → worker login headful interaktif → session tersimpan. Tanpa akun aktif, tidak ada scrape/action.

Tiket ini: Desired-state reconciler.

## Scope

`diff(desired, actual) → actions`; `Worker.desiredState` + `generation` label

## Technical Notes

Reconciler = **jalur produksi**. Di lokal tak aktif (tidak ada K8s API); diuji via unit test murni (`diff(desired,actual)`) + envtest opsional. Jangan jadikan reconciler dependensi keras untuk `make up` lokal.

Invarian kunci: 1 container = 1 device = N akun, maks 1 per platform (@@unique([workerId, platform])). Channel: queue:action:<workerId> + control-<workerId>. Commit DB SEBELUM publish/enqueue.
