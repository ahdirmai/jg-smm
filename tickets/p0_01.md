## Scope

`pnpm` workspaces + `go.work` + turbo + `packages/{shared,ui,tsconfig}`; build **arm64**

## Technical Notes

Monorepo harus build di **arm64** (Apple Silicon). Sertakan `.nvmrc`/`go.work`/`.tool-versions` dan catat prasyarat toolchain (Node 22, Go 1.23, pnpm, Docker/OrbStack) di `README.md` root.

Utamakan YAGNI — hanya bangun yang dipakai P1. Semua service: non-root, read-only rootfs, drop capabilities, HEALTHCHECK, resource request+limit. **Lingkungan build = lokal Mac M2 16 GB (docker-compose, ARM64, tanpa K8s)** — lihat `INFRA_ANALYST.md` §15.1/§15.2.
